# TESE BREAK — Aplicación de Pedidos Anticipados

## Arquitectura Tecnológica
* **Frontend Móvil:** Flutter & Dart (Android / iOS)
* **Backend y Base de Datos:** Firebase (Cloud Firestore & Firebase Authentication)
* **Control de Versiones:** Git & GitHub
* **Entornos de Desarrollo:** Visual Studio Code / Android Studio

---

## Estructura del Repositorio
* `app_flutter/` — Código fuente completo de la aplicación móvil en Flutter y Dart.
* `database/` — Esquema de colecciones, respaldos y reglas de seguridad de Cloud Firestore.
* `design/` — Diagramas UML, flujos de navegación y prototipos de interfaz.
* `docs/` — Documentación formal del proyecto (Justificación y Roles, Modelo de Diseño, Pruebas QA y Manual de Usuario).
